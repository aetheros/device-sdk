Detailed Description

GEISA waveform frame.

One frame of data from the waveform service. Samples within the data array are ordered as follows:

  • Time 0
    • All voltage channels
    • All current channels
  • Time 1
    • All voltage channels
    • All current channels
  • Time 2
    • All voltage channels
    • All current channels
  • And so on...
